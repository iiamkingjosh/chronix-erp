Module Tab Bars on Mobile

Finance, HR, Tax, Analytics and others have a row of tabs (e.g. "Invoices | Payments | Expenses | Reports"). On a phone screen these overflow. Pick the treatment.

A

Horizontally Scrollable Tabs (Recommended)

The tab bar scrolls horizontally with overflow-x: auto and hidden scrollbar. Tabs stay full-size, user swipes to see more. A fade hint on the right edge indicates overflow.

  • Familiar pattern
  • All tabs accessible

Cons

B

Dropdown Select on Mobile

Tabs collapse into a native <select> or styled dropdown on mobile. User taps to pick the section. Clean but loses the "tab" feel.

Invoices ▼

Pros

  • Works with many tabs
  • No overflow

Cons

  • Breaks visual language
  • More complex code
  • Less scannable
C

Wrap to Two Rows

Tabs wrap naturally when they overflow — no special treatment. The tab bar may use 1–2 rows on mobile.
