HR Module

Payroll That Thinks Ahead

👤

Employee Management

When HR marks all payroll as paid, PAYE tax records are automatically computed for each employee using their actual payroll salary — no separate manual step in the Tax module.


Existing records for the period are skipped to prevent duplicates. The payroll page shows a confirmation banner.


This saves 1–2 hours of manual work every payroll cycle.

Tax Module

Nigerian Tax Compliance Built In

👤PAYE

Progressive PAYE calculation using Nigeria's 6-band tax table (PITA + Finance Act 2024). Monthly and annual computation per employee. Auto-populated from payroll. Export to CSV, Excel, and PDF.

🧾VAT

Track output VAT at 7.5% on invoices and input VAT on purchases. Monthly VAT records by period. Summary dashboard showing net VAT position. Export for FIRS filing.

🏦WHT

Withholding Tax on vendor payments — 5% on services, 2.5% on goods. Track certificate issuance status. Vendor-level WHT history. WHT credit management.

🏛️Corporate Income Tax (CIT) Estimation

Live CIT estimation at 30% on taxable profit — pulled from actual invoice and expense data. YTD revenue vs expenses. Not a tax filing, but an accurate planning tool. Updated in real time as records are added.

⚠ All tax figures are estimates for internal planning. Always verify with a qualified tax advisor before filing with FIRS or LIRS.

Notifications System

The Right People, Informed in Real Time

🔔

Push Notifications

Browser push notifications via Firebase Cloud Messaging. Works on desktop and mobile. Notifications arrive even when the browser tab is not open.

📧

Email Notifications

Branded HTML email templates for key events — tax reminders, subscription alerts, PAYE completion, invoice sent confirmation. Delivered via Resend.

🎯

Role-Targeted Delivery

Every notification specifies which roles should receive it. A PAYE alert goes to CEO, CFO, and HR. A subscription alert goes to CEO, CFO, and System Admin. Staff don't see executive alerts.

🔕

Deduplication

Intelligent dedup keys prevent the same alert being sent twice for the same event. No notification floods.

📥

In-App Centre

All notifications visible in the Notifications page with read/unread tracking. Clickable links take users directly to the relevant record.

🤖

Automated Triggers

Payroll completion, PAYE calculation, subscription renewals, tax period closings — all trigger appropriate notifications automatically via cron jobs and event handlers.

Security Architecture

8 Layers of Protection

1

Firebase Authentication

Signed JWT tokens. Every request verified server-side before any data is accessed.

2

Role-Based Access Control

12 roles, granular permissions. Every button and page checks access before rendering.

3

Firestore Security Rules

Database-level enforcement. UI bypass still hits a wall at the database.

4

Next.js Middleware

Server-side route guard. Unauthenticated URL access redirected immediately.

5

API Route Auth

Every API endpoint verifies Bearer token before processing. No anonymous API calls succeed.

6

Immutable Audit Log

Every action recorded. Logs cannot be edited or deleted — full forensic trail.

7

Env Variable Isolation

All secrets stored in Vercel env vars. Never exposed to the client bundle.

8

Client Portal Isolation

External clients can only see their own records. Firestore rules enforce billing key matching.
